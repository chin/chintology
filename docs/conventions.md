# Conventions - How to write the repository? i.e. style

## Terminology

Must be exact because math.

## Naming

Python modules and packages use `snake_case`.

Markdown filenames use `kebab-case`.

Python classes use `PascalCase`.

Python constants use `UPPER_SNAKE_CASE`.

## Mathematical notation

Mathematical notation is written in LaTeX.

Inline mathematics uses `$...$`.

Display mathematics uses:

$$
...
$$

## Documentation

Architecture documentation is maintained under `docs/architecture/`.

Architectural terms are defined using Markdown definition lists.

`represented`
: Describes how mathematical or architectural content is encoded in a
  particular representation.

`define`
: Introduces mathematical meaning, an object, or notation.

`establish`
: Derives or proves a mathematical result.

`constitute`
: Describes mathematical objects and relationships that form the theory.
