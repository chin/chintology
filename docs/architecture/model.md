# Model: How is the theory represented? i.e. its language

`model` defines how those mathematical objects and relationships represented, identified, typed, attributed, and tracked.

It answers:

- How are mathematical objects represented?
- How are relationships represented?
- How are the properties of mathematical objects and relationships represented?
- How are identity, provenance, status, and verification information represented?

## Classification

`proof_role`
: The role of a mathematical object in the proof system.

`semantic_type`
: The mathematical type of a mathematical object or relationship.

`symbol`
: The mathematical symbol associated with a mathematical object when one exists.
