# Maths: What is the theory?

`maths` defines the mathematical objects and relationships that construct the theory.

It answers:

- What are the mathematical objects that constitute the theory?
- What are the relationships that constitute the theory?
- What mathematics does each object define or establish?
- What mathematical conditions and dependencies apply to each object?

## Mathematical structure

mathematical object
: An identified component of the theory with mathematical meaning.

relationship
: An identified mathematical connection between mathematical objects.

proof obligation
: A mathematical requirement that must be established before the dependent mathematical result can be established.

specialization
: A distinct mathematical object obtained by applying an defined specialization to another mathematical object while preserving the applicable inherited conditions.
