# Chintology

Chintology is a concrete manifestation of the study of the theory and proof architecture underlying the mathematical framework developed in my dissertation research.

## Architecture

- `src/chintology/maths/` defines the mathematical objects and relationships that construct the theory.
- `src/chintology/model/` defines how those mathematical objects and relationships are represented, identified, typed, attributed, and tracked.
- `docs/architecture/graphs.md` defines how the theory is surveyed through its connections and traversal.

See `docs/architecture/` for the architecture and `docs/conventions.md` for repository conventions.
